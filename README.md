## Features

- **Notebook design** with a light/dark theme toggle and a handwritten/clean font toggle.
- **Every note:** a sticky sidebar contents list with scroll-spy, a reading-progress bar, section-by-section "Got it" ticks, a scored quiz, copy buttons on code, syntax highlighting, and prev/next links across modules.
- **Progress tracking** on the roadmap, module pages and cards. It is saved in the reader's browser.
- **Full-text search** inside every section of every note (Notes page).
- **Glossary + flashcards** built automatically from each note's key terms.
- **Save as PDF:** Ctrl/Cmd + P with *Background graphics* on. Quiz answers are included.
- **Works offline:** open `index.html` straight from disk. No server needed.

## Project layout

```
index.html                 Home: hero, stats, roadmap, modules, latest notes
notes/index.html           All notes + full-text search + module filter
notes/<module>/index.html  Module page (generated)
notes/<module>/<note>/index.html   One note
glossary/index.html        Glossary + flashcards
assets/style.css           Design system
assets/site.js             Engine for every page
assets/data.js, search.js, glossary.js   Generated by the build
notes.json                 Generated site data (same as data.js)
tools/modules.json         THE source of truth: modules, note order, Drive doc IDs
tools/build.py             Build + validator
tools/AUTHORING.md         How to write a note page (components, rules)
```

## Adding or updating a note

1. Add or adjust the note's entry (slug, title, Drive doc id) in `tools/modules.json`.
2. Write `notes/<module>/<slug>/index.html` following `tools/AUTHORING.md`. Copy an existing note as a starting point.
3. Run `python tools/build.py`. It regenerates the data, search index, glossary and module pages, and lists any problems.
4. Commit and push. The note appears on the roadmap, the module page, search and the glossary.

A module with `"status": "soon"` (or with no written notes) appears on the roadmap as *Coming soon*.

## Publishing on GitHub Pages

```bash
git init && git add . && git commit -m "AIFDE notes"
git branch -M main
git remote add origin https://github.com/<you>/aifde-notes.git
git push -u origin main
```

Then go to **Settings → Pages → Deploy from branch → main / root**. `.nojekyll` is already included.
